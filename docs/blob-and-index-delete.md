# アプリからのblob削除と検索索引削除

記憶一覧の「MemWalから削除」で操作画面を開く。blob削除済みの記憶にも「blob削除済み・検索索引を確認」から入れる。

## Walrusのblobを削除

1. 所有者ウォレットを接続し、内容を確認する。
2. 「対象blobと削除取引を確認」でMainnetの所有オブジェクト全ページを照合する。
3. 対象オブジェクトを確認して削除取引に署名する。SUI手数料は所有者が負担する。
4. 対象blob・オブジェクトが一致するBlobDeletedイベントを確認して、アプリ内の記録を無効化する。自動で再保存しない。

サーバーは秘密鍵を使用しない。既存の本人ログインに加え、準備した取引そのものへの所有者署名を検証する。blob ID、型、所有者、deletableを検査し、対象が複数ある場合は自動で選ばない。取引の呼出先packageは公式MainnetのWalrus Systemオブジェクトから読み取る。

送信前に取引digestと状態を保存する。送信後の通信断では新しい取引を作らず「削除結果を確認」で同じdigestを確認する。未送信の準備は中止できる。署名依頼を拒否した場合も準備の中止・再確認が可能。

旧V1向けSecurity Delete APIは選択式で残している。通常の直接削除には旧V1削除一覧への登録は不要。

## MemWalの検索索引を削除

同じ画面の「保存区分の検索索引削除を開く」、または設定の「MemWalの検索用データをリセット」を使う。

「対象を確認」で区分名と件数を取得し、消す区分をチェックする。選択中の区分数と件数を確認して「検索リセット」と入力する。記憶から開いた場合は、サーバーでその記憶の保存区分を照合し、該当区分だけを返して初期選択する。該当区分がなければ空を返し、無関係な区分を候補にしない。実行時にも保存区分を再照合する。設定から開いた場合は全区分を表示し、初期選択しない。

選択した区分の全索引が対象で、blob 1件単位の索引削除ではない。他アプリの記憶でも同じ区分にあれば含む。未確認区分・重複区分・空の選択・期限切れ・環境変更は拒否する。各区分についてforget後にstatsの0件を確認し、部分失敗は成功と区別する。対象のローカル記録は残し、自動再送を止める。

Walrus原本の削除と索引削除は別の操作。forgetは他のblob原本を削除せず、restoreで残った原本の索引を復元できる。キャッシュや取得済みコピーの完全消去は保証しない。
