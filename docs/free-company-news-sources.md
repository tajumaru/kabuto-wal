# 無料の企業ニュース・公式IR情報源調査

調査日：2026-10-20（JST）。本変更ではニュース取得を実装しない。以下は公開公式文書で確認した導入判断であり、無料枠の登録・API実行・契約・外部同期は行っていない。

## 比較

「更新頻度」は提供者の目安であり、実際に当アプリが受信した時刻を保証しない。無料サービスでも保存・通信・保守のコストは残る。数値制限や権利範囲が確認できないものを「無制限・商用可」と扱わない。

## 公式根拠

- [トヨタ公式RSS](https://global.toyota/jp/rss_feeds/) と [サイト利用規約](https://global.toyota/jp/terms-of-use/)：購読提供と、コンテンツ・リンクの制限を合わせて確認。
- [JPX公式RSS](https://www.jpx.co.jp/rss/) と [サイト利用条件](https://www.jpx.co.jp/term-of-use/index.html)：RSS公開は二次利用の包括許可ではない。
- [EDINET利用規約](https://disclosure2dl.edinet-fsa.go.jp/guide/static/disclosure/WZEK0030.html)、[公共データ利用規約1.0](https://www.digital.go.jp/resources/open_data/public_data_license_v1.0)、[EDINET API関連資料](https://disclosure2dl.edinet-fsa.go.jp/guide/static/disclosure/WZEK0110.html)、[EDINETのAPIキー案内](https://disclosure2.edinet-fsa.go.jp/WEEK0010.aspx)。自動取得にはAPIを利用し、出典・編集主体・第三者権利を管理する。
- [NewsAPI.org規約](https://newsapi.org/terms)：Developerは開発/テスト限定、本番には使用不可。
- [TheNewsAPI規約](https://www.thenewsapi.com/tos)：無料アクセスの可否と商用・再配信の権利を混同しない。
- [GDELT利用・再配信条件](https://gdeltproject.org/about.html)、[DOC API公式仕様紹介](https://blog.gdeltproject.org/gdelt-doc-2-0-api-debuts/)、[2.0系更新頻度の公式説明](https://blog.gdeltproject.org/neural-global-entity-graph-geg-now-updating-every-minute/)：データセットの許諾と参照先媒体の権利を区別する。

## 次段階の提案（未実装）

優先順位はEDINET直接API、次に権利範囲を限定できるGDELTデータセット。企業IR/RSSは企業別の許可確認後に限定する。いずれも取得記録・原本hash・提供者の公表日・実取得日時・訂正/取消・権利範囲を独立保存し、予測cutoff以前に取得したことを確認できる資料だけを過去根拠に使う。

ニュース実装までUIは「ニュース未確認」を維持する。決算サマリーが取得できたことを、報道・会社発表の網羅的な確認と表示しない。
