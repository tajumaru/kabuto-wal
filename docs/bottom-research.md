# 底打ち研究：段階1

`/bottom`で個別銘柄を選び、取得済みの連続80営業日からRSI14、MACD、ATR14、5/20/60日平均、出来高倍率、安値からの日数等を計算します。日足がない場合はホームで監視追加し、既存の日足取得を行ってください。demoは架空データです。

10条件の配点は10/10/15/10/5/10/10/15/5/10点。条件、得点、未一致の条件、独立したリスクを表示します。スコアは未校正で成功確率ではありません。下落率15%以上と直近5日のRSI30以下が候補の前提です。売買代金とTOPIX・決算・ニュースは未確認として表示し、ランキング適格とは判定しません。

RSIとATRはWilder法。EMAは最初のn本SMAで初期化。計算は常に直近80本に固定し、出来高倍率の分母は当日を除いた20本平均。RSIが完全横ばいなら50、日足高低同値なら下ヒゲ比率0、出来高平均0なら倍率nullです。

GET `/api/bottom/analysis?code=72030&asOf=2026-10-09` はローカル参照だけを行います。外部取得、予測記録、MemWalへの書込みは行いません。実モードでは既存本人セッションが必要です。不正入力422、未知コード404、データ不足は200の`status=unavailable`、`score=null`と理由コードで返します。

基準日を指定した場合は当日JST終了までにアプリが取得したrevisionのみ使用します。過去履歴を今日初めて取得しても、過去時点で取得済みと偽りません。指定なしは現在までに取得した最新日を解析し、必要営業日と異なる場合は鮮度の注意を表示します。実データはすべてresearchで、校正済み確率は常にnullです。

80本のカレンダー連続性、正値、OHLC整合性、出来高、同じ銘柄・調整系列を検査します。系列IDがない旧データや異なる取得系列を安易に結合しません。段階2の調整系列構築が完了するまでは、既存方式で同期間をまとめて取得したデータを利用します。遡及調整・提供元訂正について完全なpoint-in-time保証はありません。

UIは銘柄・基準日、10条件、スコア、リスク、終値と5/20日平均、計算方法、デジャヴへのリンクを表示します。デジャヴへは銘柄とasOfを引き継ぎます。新しい予測スキーマや保存先はまだ導入していないため、既存JSON・暗号化バックアップの変更はありません。

全銘柄探索、日付一括取得、売買代金保存、調整系列再構成、底打ち用類似統計、予測原本・期限後評価、MemWal反省保存は後続段階です。既存デジャヴとMemWalの機能・設定は維持します。
